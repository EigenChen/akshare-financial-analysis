## 五、后续建议（下一轮）

1. 将根目录中“已归类脚本”的正文逐步迁入新目录，根目录保留薄兼容壳。
2. 新增功能一律在 apps/core 下开发，不再在根目录新增 Python 脚本。
3. 当团队使用新入口稳定后，再逐步减少根目录兼容文件。
