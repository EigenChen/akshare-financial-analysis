## 说明

当前重构采取“**先建新结构，再逐步收口旧脚本**”的方式：

1. 新目录已经可用
2. 旧入口保留兼容
3. 业务逻辑后续再逐步迁移到 `core/`
4. 学习、预研、测试脚本后续可继续从根目录清理
