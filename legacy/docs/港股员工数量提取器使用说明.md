# 港股员工数量提取器使用说明

## 📋 概述

港股员工数量提取器采用**基于多态的设计架构**，为不同公司实现定制化的员工数量提取逻辑。由于不同港股上市公司的年报格式差异较大，通用提取方法可能无法准确提取，因此需要为每个公司实现专门的提取器。

## 🏗️ 架构设计

### 核心组件

1. **抽象基类 `HKEmployeeExtractor`**
   - 定义统一的提取接口
   - 提供通用的年份提取和CSV保存功能
   - 所有公司提取器必须继承此类

2. **具体提取器类**
   - `TencentEmployeeExtractor`: 腾讯控股（00700）专用提取器
   - 可以轻松扩展其他公司的提取器

3. **工厂函数 `get_employee_extractor`**
   - 根据股票代码返回对应的提取器
   - 如果未实现，返回 `None`

## 📝 已实现的提取器

### 腾讯控股（00700）

**年报格式示例：**
```
於二零零七年十二月三十一日，本集團有4,344名僱員（二零零六年︰3,017名）
```

**提取逻辑：**
- 匹配"本集團有X,XXX名僱員"模式
- 提取当期（报告期）的员工数量
- 自动忽略括号中的上一年数据

## 🚀 使用方法

### 方法1：使用便捷函数（推荐）

```python
from 港股员工数量提取器 import extract_and_save_to_csv

# 提取并保存为CSV
csv_path = extract_and_save_to_csv(
    pdf_dir="年报PDF",
    symbol="00700",
    start_year=2020,
    end_year=2024,
    output_dir=".",
    verbose=True
)
```

### 方法2：使用提取器类

```python
from 港股员工数量提取器 import get_employee_extractor

# 获取提取器
extractor = get_employee_extractor("00700")

if extractor:
    # 提取单个PDF
    count = extractor.extract("年报PDF/00700_2024年年度报告.pdf", verbose=True)
    
    # 按年份提取
    results = extractor.extract_by_year("年报PDF", 2020, 2024, verbose=True)
    
    # 保存为CSV
    csv_path = extractor.save_to_csv(results, output_dir=".")
else:
    print("该公司的提取器尚未实现")
```

### 方法3：在统一财务工具中使用

1. 运行 `启动统一财务工具.bat`
2. 选择市场：**港股**
3. 选择功能：**👥 员工数量提取**
4. 输入股票代码、起止年份和PDF目录
5. 点击"🚀 开始提取"
6. 如果使用了专用提取器，会显示提示信息
7. 下载生成的CSV文件

## 📊 CSV文件格式

生成的CSV文件格式与A股一致：

```csv
年份,员工数量
2020,62885
2021,68226
2022,74317
2023,106836
2024,115076
```

文件名格式：`{股票代码}_员工数量.csv`

## ⚠️ 注意事项

1. **PDF文件命名**：建议使用格式 `{股票代码}_{年份}年年度报告.pdf`
2. **提取失败处理**：如果提取失败，会返回 `None`，不会抛出异常
3. **未实现的提取器**：如果某公司的提取器未实现，会使用通用提取方法，可能无法准确提取
4. **数字验证**：提取的数字会在 10 到 1,000,000 之间进行合理性验证

## 🔄 与现有系统的集成

新的多态架构已集成到现有系统中：

1. **自动选择提取器**：`extract_employee_count_by_year_from_pdfs` 函数会自动优先使用专用提取器
2. **后备方案**：如果专用提取器未实现，会自动使用通用提取方法
3. **统一接口**：保持与现有代码的兼容性，无需修改调用代码

## 💡 最佳实践

1. **先测试再集成**：为每个公司实现提取器后，先用测试脚本验证
2. **处理边界情况**：考虑不同年份可能格式略有差异
3. **添加详细日志**：在 `verbose=True` 时输出详细的调试信息
4. **文档化格式**：在提取器类的文档字符串中说明该公司的年报格式特点
